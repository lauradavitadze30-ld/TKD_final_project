TKD — 4-in-1 მრავალფუნქციური პლატფორმა

TKD წარმოადგენს ინოვაციურ, მრავალფუნქციურ ვებ-პლატფორმას, რომელიც ერთ სივრცეში აერთიანებს ოთხ ძირითად მიმართულებას: იურიდიულ მომსახურებას, შრომის უსაფრთხოებას, ბუღალტერიასა და აუდიტს.

პლატფორმის მიზანია რთული პროფესიული პროცესების გამარტივება და მომხმარებლისთვის (როგორც ფიზიკური, ისე იურიდიული პირებისთვის) ხელმისაწვდომი, თანამედროვე და მოქნილი ციფრული სერვისების შეთავაზება.

🚀 ძირითადი ფუნქციები და შესაძლებლობები
Single Page Application (SPA) როუტერი: გვერდების (#/, #/about, #/tpl, #/blog, #/book) მყისიერი ჩატვირთვა ბრაუზერში, გვერდის გადატვირთვის გარეშე.
ინტერაქტიული დოკუმენტების გენერატორი: ხელშეკრულებებისა და ოქმების ტექსტის რეალურ დროში (Real-time) განახლება, დაბეჭდვა, .docx ფორმატში გადმოწერა ან ელ-ფოსტით გაგზავნა.
ვირტუალური ასისტენტი (ჩატბოტი): ინტელექტუალური ასისტენტი სწრაფი პასუხების (Quick Reply) ფუნქციითა და Facebook Messenger-ში გადამისამართებით.
ორენოვანი მხარდაჭერა (KA/EN): საიტის ტექსტების დინამიური თარგმნა ქართულ და ინგლისურ ენებს შორის.
ხელმისაწვდომობის პანელი (Accessibility Suite): სპეციალური მენიუ მხედველობადაქვეითებული და შეზღუდული შესაძლებლობის მქონე პირებისთვის — შრიფტის ზომის შეცვლა (87.5%-200%), High Contrast, Clear Font, Large Spacing, ანიმაციების გამორთვა, კითხვის ხაზი და ხმოვანი წაკითხვის ფუნქცია (Web Speech API).
მონაცემთა ავტომატური შენახვა (Auto-save): დაჯავშნის ფორმაში შეყვანილი ინფორმაციის შენახვა LocalStorage-ში, გვერდის შემთხვევით დახურვისას მონაცემთა დაკარგვის თავიდან ასაცილებლად.

HTML5: სემანტიკური სტრუქტურა (<header>, <main>, <nav>, <section>, <article>, <footer>) SEO-სა და Accessibility-სთვის.
CSS3: Custom Properties (CSS ცვლადები), Flexbox, CSS Grid, მედია-მოთხოვნები (Responsive Design, prefers-color-scheme, prefers-reduced-motion).
